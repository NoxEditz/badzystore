# Core Standards
- Prefer TypeScript over JavaScript for new files unless the project is already JS-only
- Always write clear commit-message-style summaries after completing a task
- Never modify files outside the current working directory without asking first
- Ask before installing new dependencies — explain why each one is needed
- Write tests for new functions when a test framework exists in the project
- Keep functions small and single-purpose; flag files over 300 lines for possible splitting
- Never hardcode API keys, secrets, or credentials — use environment variables
